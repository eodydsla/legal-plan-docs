# 환경분야 법정계획 정리

환경 관련 법정계획을 수집·검증해 마크다운으로 정리한 저장소다.
1차 수집은 국토환경정보센터, 2차 검증은 소관부처 공표자료를 썼다.

|---|---|---|

**작업 결과물은 앞의 문서다.** 뒤의 전체 목록은 1차 수집 원본이라 최신 차수가 반영돼 있지 않다. 계획부문·근거법령 등 전수 현황을 볼 때만 참고한다.

## 1. 기본계획·종합계획 차수별 목록 (58개 계획 / 131개 차수)

계획부문이 기본계획·종합계획인 58건만 추려, 제1차부터 현행 차수까지 전부 적었다.
필드는 `연번 · 계획명 · 근거법률 · 근거조문 · 차수 · 계획기간 · 갱신주기 · 소관부처 · 신뢰도 · 원문`.

- 신뢰도(차수 단위): 확인 73 · 참고 32 · 미확인 15 · 해당없음 11
- 출처 사이트가 놓친 최신 차수 7건을 확인
- 출처 사이트에 없는 환경분야 기본·종합계획 8건을 추가 발굴
- 해양수산부 소관 해양환경 계획 5건, 경계 항목(적응대책·NDC·기본방침) 8행을 별도 정리

5차까지 이어진 계보 예시

| 계획 | 차수별 계획기간 |
|---|---|
| 국가환경종합계획 | 1987~2001 → 1996~2005 → 2006~2015 → 2016~2035 → 2020~2040 |
| 소음·진동관리 종합계획 | 2006~2010 → 2011~2015 → 2016~2020 → 2021~2025 → 2026~2030 |
| 실내공기질 관리 기본계획 | 2004~2008 → 2009~2013 → 2015~2019 → 2020~2024 → 2025~2029 |
| 야생생물 보호 기본계획 | 2006~2010 → 2011~2015 → 2016~2020 → 2021~2025 → 2026~2030 |
| 국가생물다양성전략 | 1997 → 2009 → 2014~2018 → 2019~2023 → 2024~2028 |

## 2. 전체 목록 (150개)

국토환경정보센터 원 데이터를 가공 없이 옮긴 것이다. 계획부문·근거법령별 집계와 첨부 보고서 235건 다운로드 링크를 담았다.

- 근거법령 54개 · 계획부문: 기타 54 · 기본계획 45 · 시행계획 18 · 관리계획 14 · 종합계획 13 · 실시계획 3 · 세부계획 2 · 실천계획 1
- 첨부 보고서 보유 104개 계획 / 235건

## 수집·검증 방법

**1차 수집** — [국토환경정보센터 자료제공서비스 › 환경관련 법정계획](https://data.neins.go.kr/bbs/legalPlan)
페이지가 React SPA라 HTML에 데이터가 없어, 번들 JS에서 내부 API를 찾아 직접 호출했다.

- `/kei/legalPlan/list.json` — 계획 150건
- `/kei/legalPlan/fileList.json?sttyPlanIdx={idx}` — 계획별 첨부 보고서 (150건 전수 조회, 235건)

**2차 검증** — 출처 사이트는 차수·계획기간 항목 자체가 없고 첨부 보고서도 오래된 것이 많아, 계획명별로 아래를 대조했다.

- [기후에너지환경부 정책자료](https://www.mcee.go.kr/home/web/policy_data/list.do?menuId=10259) — 공표본 제목에서 차수·기간 추출 (전수 검색)
- [기후에너지환경부 보도·설명자료](https://www.me.go.kr/home/web/board/list.do?menuId=10525)
- [대한민국 정책브리핑 정책DB](https://www.korea.kr/archive/) · [국가기록원](https://www.archives.go.kr/) — 1990~2010년대 과거 차수
- [국가물관리위원회](https://www.water.go.kr/) · [산림청](https://www.forest.go.kr/) · [해양수산부](https://www.mof.go.kr/) — 타 부처 소관 계획
- [국가법령정보센터](https://www.law.go.kr/) — 근거조문·수립주기

검증일 2026-08-22. 소관부처는 2026년 정부조직 개편에 따라 **기후에너지환경부**(구 환경부)로 적었다.

## 알려진 한계

- **미확인 15행** — 차수 존재는 확인되나 계획기간을 특정하지 못했다. 수변구역관리기본계획 제1~3차(4개 수계), 환경시험·검사 발전 기본계획 제1~3차, 화학물질 평가 기본계획, 환경기술·환경산업 육성계획 제1~4차가 대표적이다. 부처 게시판·웹 어디에도 원문이 없어 정보공개청구가 필요해 보인다.
- **해당없음 11행** — 지자체·시설·하천 단위로 개별 수립되는 계획이라 국가 단위 차수 개념이 없다.
- 해양수산부 소관 해양환경 계획은 현행 차수만 적었고 과거 차수는 검증하지 않았다.
- 전체 목록(150개)은 검증 대상이 아니었다. 여기 실린 차수 정보는 첨부 보고서 파일명에서 뽑은 값이라 최신이 아닐 수 있다.
